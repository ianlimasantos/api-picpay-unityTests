# PicPay Simplified Payment API 🚀

Este projeto é uma API REST desenvolvida em **Java** com o framework **Spring Boot**, simulando uma versão simplificada do ecossistema de pagamentos do PicPay.

O foco principal deste repositório foi a **implementação robusta de testes unitários** para garantir a confiabilidade das transferências, regras de negócio e validações do sistema.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Linguagem:** Java 17
- **Framework:** Spring Boot 3
- **Banco de Dados:** H2 Database (Ambiente de Testes/Desenvolvimento)
- **Gerenciador de Dependências:** Maven
- **Testes Unitários:**
    - **JUnit 5** (Estruturação dos testes)
    - **Mockito** (Mocking de serviços, repositórios e chamadas externas)
    - **AssertJ** (Asserções fluídas e legíveis)
